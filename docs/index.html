    How they scored

    Cross-entropy on held-out text, in nats per character; lower is better. Guessing uniformly over all 65 characters scores 4.17 (dashed line). Each model trained for 7,500 steps on the same batches.

    The weights come from the PyTorch checkpoints and run in your browser. The JavaScript forward passes match PyTorch to within 1e-4.
